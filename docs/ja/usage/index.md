# 使い方

Qamomileの機能やAPIの使い方を目的別に紹介します。

::::{grid} 1 1 1 1

:::{card}
:header: **不変なBinary・Spinモデル**
:link: binary_model
任意ID、energy、Hamiltonian、decode、persistence、OMMX評価を1つのRust実装モデルで扱います。
:::

:::{card}
:header: **量子ビット列の操作**
:link: qubit_arrays
量子ビット列の一部へのゲート操作、部分ごとに処理するための分割、次の処理へ渡すための結合を紹介します。
:::

:::{card}
:header: **リソース推定の詳細ガイド**
:link: resource_estimation
個々のリソース指標の意味、推定結果の保存・復元、物理リソースの推定とその仮定を確認します。
:::

::::
